# 账号规划 · 单人自拍口播 · 快消品带货方向（数据支撑版）

> 推导逻辑（用户指定，倒推法）：**最终要卖什么 → 反推要什么样的人群 → 反推应该做什么样的内容**。
> 每一层都尽量挂系统真实数据，无法用数据实锤的部分明确标注"反推/待起号验证"，不拍脑袋。

---

## 一、商业目标（推导起点，用户提供）

| 项 | 内容 |
|---|---|
| 卖什么 | **快消品**：① 纸品（抽纸/卷纸/湿巾/厨房纸）；② 预包装食品（零食/方便速食/冲调/调味） |
| 变现形态 | **带货**（抖音/快手为主，口播自拍天然契合） |
| 品类属性 | 低客单、高频复购、刚需、品牌可替代性强 → **转化核心是"人设信任 × 性价比"** |

## 二、推导链总览

```
卖：纸品 + 预包装食品（带货）
  │  反推消费行为
  ▼
人：家庭采购决策者(25-45女性为主) + 都市独居/打工青年(20-35) ｜ 共性=性价比敏感、为真实信任买单
  │  反推他们爱看什么、什么能自然导向带货
  ▼
内容：用口播能力(观点/情绪/故事/人设)包装"消费/性价比/家庭/育儿/食品"切口 → 5个栏目
```

## 三、人群推导（数据支撑）

### 3.1 反推逻辑
纸品是**家庭刚需**（决策在采购者，看安全/性价比/囤货）；预包装食品覆盖**一人食/加班/深夜**场景（决策在年轻人，看方便/口味/价格）。两者交集人群：**为"省心+省钱+真实"买单，信任真人测评高于广告**。

### 3.2 数据支撑（系统 KB 实证，非臆测）
从 `knowledge_base` 常青选题（共 552 条）中筛出 **58 条与快消带货直接相关**，类别分布：

| KB 类别 | 命中数 | 说明 |
|---|---|---|
| 观点·立场线 | 34 | **占主导**——"消费/性价比/物价"类观点内容最易爆 |
| 人物·命运线 | 15 | 家庭/育儿/打工人故事，情绪触达强 |
| 社会·观察 | 6 | 食品/消费事件（涨价、事故） |
| 突发·现场 | 3 | 食品厂安全等现场感 |

**关键证据选题（按 durability 降序，直接支撑人群与切口）**：
- `康师傅回应一包泡面近20元` dura=86 → 预包装食品涨价，人群痛点
- `中产的下一个抠门对象：超级双11` dura=18、`双11购物清单回归刚需` dura=7、`今年双11货架电商怎么又行了` dura=7 → **大促/性价比是超级常青切口**
- `为啥车厘子越来越便宜` dura=7、`深圳车厘子刚上市就降价` dura=7 → 食品价格话题
- `山姆超市一羽绒服卖断货` dura=10、`商场看中羽绒服网上便宜一千` dura=10、`便宜五千的加拿大鹅治不好山姆的焦虑` dura=11 → 中产超市/性价比
- `幼儿园陆续消失 育儿焦虑退潮` dura=10、`家长让孩子只上半天学` dura=39、`京东员工孩子换幼儿园` dura=10 → **育儿/家庭采购人群真实活跃**
- `秋冬厚衣服怎么洗烘更省心` dura=5 → 清洁/日化场景
- `多少公斤体重每天吃多少蛋白质` dura=7 → 食品/健康

> 结论：这群人**不仅存在，而且在你的选题库里反复出常青爆款**。"消费/性价比/家庭/育儿/食品"是已被数据验证的高频切口——这是规划不拍脑袋的底气。

### 3.3 人群画像（反推 + 标注）
| 维度 | 反推画像 | 置信度 |
|---|---|---|
| 核心人群 | 25-45 岁家庭采购决策者（女性为主） | 中（话题反推，无 demographics 实证） |
| 次核心 | 20-35 岁都市独居/打工青年 | 中（场景反推） |
| 决策驱动 | 性价比、真实测评、囤货省心 | 高（KB 常青证据强） |
| 平台 | 抖音/快手（快消带货第一阵地） | 高（品类常识+行业共识） |
| 不买账 | 硬广、过度营销、虚高人设 | 高（信任敏感） |

> ⚠️ 诚实声明：系统无粉丝年龄/地域/收入等 demographics，人群为**从话题行为反推**，需起号后用真实画像回验。

## 四、人设定位（匹配口播能力库）

**人设一句话**：「真实、懂生活、帮你省的真人采购搭子」——不装专家，只替你试、替你比、替你砍价。

## 六、平台与节奏

- **主阵地**：抖音（快消带货第一流量+货架闭环）；快手为辅；小红书做种草沉淀。
- **更新节奏**：日更 1 条（栏目 1/2/3 轮流）+ 周更 1 条深度（栏目 4/5）。
- **冷启动**：先用栏目 2（双11/性价比）借势大促流量，用"真实测评"建立信任。
- **合规**：沿用 `content_safety.json` 拒识清单；带货须明示"广告/合作"，不夸大功效（尤其食品/纸品安全表述）。

## 七、数据支撑说明（现有支撑 + 缺口 + 待补源）

### ✅ 现有可支撑
- KB 常青 552 条，其中 **58 条快消带货相关**，证明"消费/性价比/家庭/食品"切口高频且易爆。
- 百度垂直榜实时在热：finance（产业/消费）、technology（双11/消费测评）——与栏目 5 源头砍价呼应。
- 口播能力库/框架库已就绪，可直接套 5 栏结构。

### ⚠️ 数据缺口（必须坦白）
- **快消选品源已接入**：什么值得买（smzdm）已作为 `smzdm_pick` 源实时采集，按"纸品+预包装食品"过滤入库，看板「选品情报」面板直接展示商品名/品类/链接——**"卖什么具体选品"已数据驱动**。但 smzdm 仅单源、热度不公开，具体卖点/价格以商品页为准，需人工二次筛选。
- 系统**无 demographics**（粉丝年龄/地域/收入），人群仍为反推，需起号后验证。
- 可选扩容：抖音带货榜/巨量算数、淘宝/拼多多热销榜（需确认免登录可用性）可进一步丰富选品维度。

| 源 | 状态 | 用途 | 合规 |
|---|---|---|---|
| 什么值得买（smzdm_pick） | ✅ 已接入 | 纸品/预包装食品选品（商品名/品类/链接） | 免登录公开页；无 PII |
| 抖音带货榜 / 巨量算数 | 可选 | 选品热度、品类趋势 | 需确认免登录可用性 |

> smzdm 已让"卖什么具体选品"从"泛话题映射"升级为"选品数据驱动"；其余源可按需扩容。

## 九、起号后验证回路（数据飞轮）

```
什么值得买首页(免登录) → a_smzdm 解析 onclick 内 dataLayer JSON
  → 按 纸品/预包装食品 过滤 → trends(trend_source=smzdm_pick) 入库
  → 看板 /api/all 的 smzdm 字段 → 「选品情报」面板（分纸品/食品两栏 + 看商品链接）
```

- 已在 `source_catalog` 注册（**19 源 / 8 平台**，审计 D 组 PASS）。
- 不进 `PRIMARY_SOURCES`，**不会污染口播选题智库**。
- 用法：每日看面板里的纸品/食品在榜选品 → 结合第五节 5 栏目做"测评/清单/场景"内容 → 挂车转化。

## 十、结论

- **卖什么**：纸品 + 预包装食品，带货形态——已由用户定。
- **人群**：家庭采购决策者 + 都市性价比青年；"消费/性价比/家庭/育儿"切口已被 KB 58 条常青选题实证高频易爆。
- **内容**：5 个栏目，主推"观点+性价比"线（踩中 KB 占比最高的 `观点·立场线`），用口播能力库落地。
- **选品侧已闭环**：什么值得买（smzdm）已接入，看板「选品情报」面板实时给出纸品/食品在榜选品，"卖什么"已数据驱动；**人群 demographics 仍需起号后用真实数据回验**。
