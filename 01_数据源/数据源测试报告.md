## 三、能力边界（诚实界定，避免夸大）

**已实现且可持续**：

- 抖音 / 微博 / 百度**实时热榜**的定时采集与历史留存；
- B站**公开榜单**创作者与作品的指标时序快照、跨轮增长（实测 4 轮已算出播放增量）；
- 跨平台热点聚合成**候选选题机会**（P0/P1/P2 分级）；
- 作品规则化速览标签（标题特征 / 时长带 / 分区 / 互动率）。

**未实现（受官方硬约束 + 合规边界，非技术能力问题）**：

- 任意指定竞品账号的全量作品 / 评论明细：抖音开放平台 API 只服务「授权用户自己的账号」，个人主体不可申请（见官方渠道调研报告第三、五节）；
- `comments` 表**刻意保持为空**：评论含个人信息，按任务书不采、不存 PII；
- 粉丝数 / 账号级指标：公开榜单不提供，`creator_snapshots` 存的是「本轮上榜作品聚合」，语义已在 `raw_metrics_json.basis` 明确标注，`follower_count` 留空。

## 四、合规声明

仅访问免登录、公开可访问的官方榜单 / 热点接口；不携带任何登录态或 cookie；不生成 / 伪造 a_bogus、X-Bogus、WBI 等反爬签名；不触发或绕过验证码 / 二次验证 / 设备校验；带 UA + Referer、每域名限速、失败重试有上限；原始响应按任务书分层落 `raw/` 便于追溯。所有入库记录带 `source / source_url / collected_at / data_status` 四件套。

## 六、已停用方案（历史，不再启用）

「真实浏览器（Playwright + Chromium）+ 用户扫码登录 + 短信二次验证 + 登录态 cookie + 拦截抖音 API 响应」。该链路实测反复失败（二维码静默轮换、双重叠 React 受控输入框、验证码时效作废），且合规定性不成立（第〇节第 2 条）。相关脚本已归档 `tools/_deprecated/`，凭证 / 二维码 / 调试文件已删除并加入 `.gitignore`。

### 7.5 诚实边界

- 网易热点流含自媒体/标题党内容，系统**不做主观过滤**，保留原文链接、发布时间与来源媒体，由创作者点开核实。
- 知乎/网易不公开热度，用 `heat_available=0` + `heat_value=NULL` 标记，看板显示「—」，**不填 0 假装是真实热度**；质量自检按此区分设计口径与缺陷。
- 抖音「入站必刷 / 分区榜」是作品维度补充，仍**不是任意第三方账号的全量明细**（官方硬约束不变）。
- 全部请求带 UA + Referer、每域名限速、重试有上限；不带 cookie、不生成签名、不绕过验证码。
